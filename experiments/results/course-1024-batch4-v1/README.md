# Archived experiment results

This directory contains the automatic metrics, AI-assisted single-reviewer ratings and provenance, and three selected comparison sheets used by the reports. Ratings are not an independent human blind study. Reference-region annotations remain assistant drafts. Full model weights, datasets, and all 96 generated outputs are excluded; their original local paths are retained in the reports for reproducibility.

The RESULTS.md automatic-evaluation snapshot predates the completed AI-assisted review; see HUMAN_REVIEW.md and ratings.provenance.json for the current review status.
